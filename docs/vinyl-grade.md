# Separate vinyl grade — draft only

Adds Recommend a grade / Commercial / Premium, with Spanish options Recomiéndenme una opción / Comercial / Premium. Context beneath the selector uses shop-supplied information: General Formulations and Canvas Escape for Commercial (including the quoted Double PR Liner, Gloss / Light Grey Adhesive description), and 3M, Avery Dennison, Aura, KPMF, Evolv, ORACAL, TeckWrap, Aluko Vinyl and other premium films for Premium. Brands are examples, not universal product suitability guarantees; printable films are distinguished from color-change films and PPF, with exact film confirmed by application. Production roll dimensions are never used as project dimensions. The grade field applies to Printed vinyl (general, vehicle panels and replacement panels), including retained wholesale links. Other products and cutting_lamination do not save a grade. Changing away resets the hidden selection. Material and lamination remain separate; no price, warranty, or durability promise is introduced.

Saved as productionRequest.vinylGrade (recommend/commercial/premium), with its localized label in message. Existing service IDs and aliases are unchanged. Generic nested productionRequest sanitization supports this field; no backend deployment is required for Canvas persistence. The future CRM-supported message retains the grade; typed CRM ingestion remains separate. No existing record is rewritten.

Branch depends on PR #4 head d0fe367f5a25bd971fccdddfd9ad497de02a4323. PR #4 deployed as a live-source overlay, so its tracked main.js/CSS prefixes are not a complete production baseline. A future approved Hosting release must patch the current live quote block rather than deploy this checkout wholesale. No Functions, rules, index, CRM activation, notification sends or recovery are included. No deployment authorization.

Validation: npm run test:quote (41 tests). Bilingual tests cover actual conditional visibility and summary updates, all grade values through the saved-record sanitizer, general/panel/legacy-wholesale routing, separate lamination, omission on irrelevant products, invalid values and CRM-readable summary mapping. Production submissions are not used.
